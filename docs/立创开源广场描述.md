## USB 3.0 信号整形器（测试用 · PI3EQX7502）

**一句话**：一块串在 USB 3.0 链路中间、带 8 位拨码的信号整形测试板 —— 81 种 EQ / DE 增益组合随手切换，用来把"长线下 SuperSpeed 掉速"这件事测清楚。

【插入图片：实物照片】

### 这是什么

这是一块**测试用的板子**，不是一个准备装进机器里长期跑的成品。

它串在主机和外设之间，用 PI3EQX7502 对衰减的 5 Gbps 信号做**均衡（EQ）+ 整形 + 去加重（DE）**后重新驱动出去，相当于给信号"续一程"。再配合 8 位拨码 —— 4 个配置脚 × 三电平 = 3⁴ = **81 种增益组合全在板子上**，不用动烙铁，可根据实际工况快速调试。

此前另开发过一块四路版本（带 DP 与网口），是往整机里装的，但发现调试增益很困难：四路同时工作，改一次配置要动 4 套电阻，通道之间还有串扰和供电耦合，测出的结果说不清是哪一路的功劳。**可优先通过该板进行增益调试，调稳后再固化到多路版。**

> ⚠️ 整形 ≠ 重定时。PI3EQX7502 只做模拟信号调理，**不做协议层重定时（那是 Retimer 的活）**，抖动会累积。这不是调参能绕过的物理限制。

### 它能用来测什么

**① 测链路 —— 判断长线到底是不是元凶**

同样是"设备能识别但跑不动"，原因可能是线缆、可能是座子、可能是主机口。这块板提供了一个干净的对照实验：长线直连跑一次（复现降级）→ 串入本板跑一次（速率回来）→ 结论就出来了。只有这两步都做到，才能说问题确实出在信号衰减上。

**② 测增益 —— 找出"够用"和"过头"的边界**

拨码的意义就在这儿。改一组配置 = 拨一下开关，不用换料不用焊，配合 `lsusb -t` 看速率、配合压力测试看掉线，很快能摸到边界在哪。EQ 开太大会连噪声一起放大，H 档反而变差就退回 M —— 这种"试出来"的经验，靠看数据手册是得不到的。

**③ 测线缆和外设 —— 反过来用它当基准**

板子状态已知、可复现，那它就是一把尺子：同一套配置下换几根线，哪根线材好、哪根差，一眼能看出差别。作者的体会是，**换线这一步的收益常常比调参更大**。

### 实测参考

作者的一组数据（只是其中一个样本，不代表距离上限 —— 线缆、外设、主机不同，结果会有差异）：

```
Jetson Orin ──30cm 公转公(A公-A公)──► U11 ──► ReDriver ──► USB5 ──3m 公转 Micro-B──► RealSense D450
位 1、位 7 ON → EQ_A=L(3dB)、DE_A=M(−3.5dB)、EQ_B=M(6dB)、DE_B=L(0dB)
```

| 场景                | 结果                               |
| ----------------- | -------------------------------- |
| 不加本板，3 m 线直连      | ❌ 能识别，但**降级到 USB 2.0（480 Mbps）** |
| 串入本板              | ✅ 正常跑在 **USB 3.0（5 Gbps）**       |

同样的 3 m 线，串上板子从 480M 变 5000M —— 对深度相机就是"能不能跑满分辨率和帧率"的分界线。

> Orin 只是作者遇到的场景。**这块板不挑主机** —— 只要主机和外设之间有一段长线缆，工控机、x86 主机、其他 ARM 板都一样适用。

| U11     | HC-USB3.0-L257-P | 主机侧 USB 3.0 Type-A 母座（板边侧插）              |
| USB5    | GSB412137CHR     | 外设侧 USB 3.1 Type-A 母座（立式，Amphenol）       |
| U1      | AMS1117-3.3S     | LDO，VBUS 5V 降 3.3V                       |
| SW1     | DSHP08TSGER      | 8 位拨码开关，配置 EQ / DE 三电平                   |
| RN1/RN2 | 4D03WGJ0472T5E   | 4.7kΩ × 4 排阻，配置脚上下拉                      |
| C1~C4   | 100nF 0402       | SuperSpeed 差分对 AC 耦合电容                   |

2 层板，43.59 × 57.42 mm，2 个 M3 安装孔（孔距 24.0 mm），从主机侧 VBUS 取电，无需外接电源。

【插入图片：原理图截图】

**信号链路**：A 通道跑上行（外设→主机），B 通道跑下行（主机→外设）；USB 2.0 的 D± 直连、不进 ReDriver（480 Mbps 衰减本来就小，且是半双工同一对线，单向整形器没法中继）。两个座子都是 Type-A 母座 —— 这块板是**串在链路中间**的，不是终端接口。

> AC 耦合电容只在 ReDriver **输出侧**：规范要求隔直电容由发送端提供，Host 和 Device 送出的信号内部已经隔直过了，而 ReDriver 的 CML 输出自带直流偏置，必须自己提供。

### EQ / DE 拨码配置

`EQ_A`/`DE_A`/`EQ_B`/`DE_B` 四个三电平脚，用 SW1 拨码切换（上拉 ON = **H**，都 OFF = **M**，下拉 ON = **L**）：

| 配置脚    | 上拉位 | 下拉位 |
| ------ | --- | --- |
| `EQ_A` | 位 8 | 位 7 |
| `DE_A` | 位 4 | 位 3 |
| `EQ_B` | 位 6 | 位 5 |
| `DE_B` | 位 2 | 位 1 |

| 档位          | EQ 均衡量 | DE 去加重量 |
| ----------- | ------ | ------- |
| **L**       | 3 dB   | 0 dB    |
| **M**（芯片默认） | 6 dB   | −3.5 dB |
| **H**       | 9 dB   | −6 dB   |

**EQ 补偿输入之前的线缆，DE 补偿输出之后的线缆** —— 长线在哪一侧，就加大那一侧。

【插入图片：拨码开关位置与位号标注照片】

**扫描建议**（每次只改一个配置脚，改完记录）：

1. 全部拨到 OFF（四个脚都在芯片默认 M 档），跑一次拿基线；
2. 长线在外设侧就加大 `EQ_A` + `DE_B`，在主机侧就加大 `EQ_B` + `DE_A`，两侧都长就逐级往上推，别一次拉满；
3. 链路不稳 / 掉线 → EQ 往上调（3 → 6 → 9 dB）；过冲 / EMI → DE 往下调（−6 → −3.5 → 0 dB）。

拨码不需要断电（纯电平配置，实时生效），但链路会重新训练，外设会短暂断开重连。

- **作者的实测配置**（3 m 内可直接抄）：位 1、位 7 ON，其余 OFF
- **想压更远（4~5 m+）**：位 2、位 8 ON，其余 OFF → `EQ_A`=H(9dB)、`DE_B`=H(−6dB)

### 怎么用

```
主机 ──[短线，尽量 < 0.5 m]──► U11 ──► ReDriver ──► USB5 ──[长线：需要覆盖的距离]──► 外设
```

1. **U11** 用短线接主机 —— 越短越好，这段线本身也会衰减；
2. **USB5** 接长线和外设；
3. 板子从主机侧 VBUS 取电，无需外接电源。

```bash
lsusb -t    # 5000M ✅ 正常 | 480M ❌ 降级
```

**别一上来就接长线**，按这个顺序能快速定位问题出在哪一环：

1. 短线直连（< 1 m）—— 先确认主机和外设本身能跑 5000M；
2. 长线直连 —— 复现降级，作为对照组（**如果这里还是 5000M，说明这个距离本来就没问题，不需要本板**）；
3. 串入本板 —— 速率应回到 5000M；
4. 压力测试 —— `dmesg -w | grep -i usb` 看有无 reset / disconnect；相机类满分辨率满帧率连续采集看掉帧；
5. 按需调参。

**看到 480M 的排查顺序**：

1. **先换主机侧那根 A公-A公线** —— 两侧都是母座，主机侧只能用 A公-A公，这种线不符合 USB-IF 规范、市售接法不统一，**是最常见的坑**；
2. 测 U3 pin 1 是否为 3.3V，确认上电；
3. 把外设侧线缆缩短到 1 m 内试，确认不是超出距离极限；
4. 按长线所在侧调档。

### ⚠️ 复刻前请注意

1. **PI3EQX7502AI 已 NRND**（不建议新设计用），官方点名替代型号 **PI3EQX7741AI**（引脚兼容性需自行核对，本项目未验证）。下单前查立创 C526708 库存。
2. **焊接难度中等偏上**：TQFN-24（0.5mm 间距 + 中心裸焊盘）+ 0402 + 两个通孔 USB 座。建议开钢网 + 热风枪/加热台，**EP 裸焊盘必须焊接接地**（它是主要散热路径和内部地参考）。
3. **这块板没做严格 90 Ω 阻抗控制**（2 层板 1.6 mm FR-4 上做 90 Ω 需约 12~15 mil 线宽，本板 5~10 mil，实际约 100~120 Ω）。实测仍能过是因为板内走线很短（最长 17 mm），主要瓶颈在线缆不在 PCB。追求性能就下单时要求"USB 3.0 差分对按 90 Ω ±10% 阻抗控制"，或改 4 层板。

> 已修复：底层丝印未镜像（52 处）+ 位号朝向不正（13 处），`silkFlipped` 55→0、ERROR 52→0。

> **复刻提示**：目标是"装到机器里用"的话，把本板测出的配置固化成固定电阻更合适（省掉 SW1 和 8 颗 4.7 kΩ）。这块板的价值在于 —— 在动手做最终版本之前，先把增益配置这块的不确定性测清楚。
