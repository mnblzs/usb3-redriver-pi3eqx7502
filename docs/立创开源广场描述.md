## USB 3.0 ReDriver 中继板（PI3EQX7502）

**一句话**：一块串在链路中间的小板，让整机通过多次转接＋3 米线缆也能跑满 USB 3.0，深度相机正常识别

### 解决什么问题

工作中遇到机器人上 Orin（Jetson Orin）装在机身内部，深度相机要装在外壳或机械臂末端。用户接口需要通过转接线+接口板的方式对外输出。外接线缆一长，5 Gbps 的 SuperSpeed 信号衰减到链路训练失败，主机自动回落到 USB 2.0 —— 设备能识别但跑不动 USB 3.0。

> Orin 只是作者遇到的场景。**这块板不挑主机** —— 只要主机和外设之间有一段长线缆，工控机、x86 主机、其他 ARM 板都一样适用。

本板串一颗 USB 3.0 ReDriver 在链路中间，做均衡 + 整形 + 去加重后重新驱动，相当于给信号"续一程"。

**实测参考**：3 m 线直连降级到 480 Mbps ❌ → 串入本板后稳定 5 Gbps ✅（这是作者的一组数据，仅为样本之一，不代表距离上限）

作者的实测接线，你不必照搬：

```
Jetson Orin ──30cm USB公转公(A公-A公)──► U11 ──► ReDriver ──► USB5 ──3m USB公转Micro-B──► RealSense D450
```

### 硬件

| 位号      | 器件               | 说明                                       |
| ------- | ---------------- | ---------------------------------------- |
| U3      | PI3EQX7502AIZDEX | USB 3.2 Gen1 5 Gbps 双通道 ReDriver，TQFN-24 |
| U11     | HC-USB3.0-L257-P | 主机侧 USB 3.0 Type-A 母座（板边侧插）              |
| USB5    | GSB412137CHR     | 外设侧 USB 3.1 Type-A 母座（立式，Amphenol）       |
| U1      | AMS1117-3.3S     | LDO，VBUS 5V 降 3.3V                       |
| SW1     | DSHP08TSGER      | 8 位拨码开关，配置 EQ / DE 三电平                   |
| RN1/RN2 | 4D03WGJ0472T5E   | 4.7kΩ × 4 排阻，配置脚上下拉                      |
| C1~C4   | 100nF 0402       | SuperSpeed 差分对 AC 耦合电容                   |

2 层板，43.59 × 57.42 mm，2 个 M3 安装孔（孔距 24.0 mm），无需外接电源。

> **这块板的定位**：单通道 + 8 位拨码，是用来摸索 EQ / DE 增益配置组合的**标定板**，不是最终装机形态。拨码让 3⁴ = 81 种组合全在板子上，扫完常用配置只要几分钟 —— 换成固定电阻就得每次换料重焊。定型之后把测出的配置固化成电阻，可以省掉 SW1 和 8 颗电阻。

**信号链路**：A 通道跑上行（外设→主机），B 通道跑下行（主机→外设）；USB 2.0 的 D± 直连不进 ReDriver。两个座子都是 Type-A 母座 —— 这块板是**串在链路中间**的，不是终端接口。

### EQ / DE 拨码配置

`EQ_A`/`DE_A`/`EQ_B`/`DE_B` 是三电平脚，用 SW1 拨码切换（上拉 ON = **H**，都 OFF = **M**，下拉 ON = **L**）：

| 配置脚    | 上拉位 | 下拉位 |
| ------ | --- | --- |
| `EQ_A` | 位 8 | 位 7 |
| `DE_A` | 位 4 | 位 3 |
| `EQ_B` | 位 6 | 位 5 |
| `DE_B` | 位 2 | 位 1 |

| 档位          | EQ 均衡量 | DE 去加重量 |
| ----------- | ------ | ------- |
| **L**       | 3 dB   | 0 dB    |
| **M**（芯片默认） | 6 dB   | −3.5 dB |
| **H**       | 9 dB   | −6 dB   |

**EQ 补偿输入之前的线缆，DE 补偿输出之后的线缆** —— 长线在哪一侧，就加大那一侧。

**作者的实测配置**（3 m 内可直接抄，更长距离建议自己扫一遍）：位 1、位 7 ON，其余 OFF → `EQ_A`=L(3dB)、`DE_A`=M(−3.5dB)、`EQ_B`=M(6dB)、`DE_B`=L(0dB)。与作者另一块四路板（内部项目，暂不开源）推出的结果一致。

**想压更远（4~5 m+）**：位 2、位 8 ON，其余 OFF → `EQ_A`=H(9dB)、`DE_B`=H(−6dB)。

> EQ 不是越大越好，开太大会连噪声一起放大。

### 怎么用

本板串在主机和外设之间，两侧都是 Type-A 母座：

```
主机 ──[短线，尽量 < 0.5 m]──► U11 ──► ReDriver ──► USB5 ──[长线：你要覆盖的距离]──► 外设
```

1. **U11** 用短线接主机 —— 越短越好，这段线本身也会衰减；
2. **USB5** 接你的长线和外设；
3. 板子从主机侧 VBUS 取电，无需外接电源。

```bash
lsusb -t    # 5000M ✅ 正常 | 480M ❌ 降级
```

**降级了按这个顺序排查**：

1. **先换主机侧那根 A公-A公线** —— 两侧都是母座，主机侧只能用 A公-A公，这种线不符合 USB-IF 规范、市售接法不统一，是最常见的坑
2. 测 U3 pin 1 是否为 3.3V，确认上电
3. 把外设侧线缆缩短到 1 m 内试，确认不是超出距离极限
4. 按长线所在侧调档：长线在外设侧就加大 `EQ_A` + `DE_B`，在主机侧就加大 `EQ_B` + `DE_A`

### ⚠️ 复刻前请注意

1. **PI3EQX7502AI 已 NRND**（不建议新设计用），官方点名替代型号 **PI3EQX7741AI**。下单前查立创 C526708 库存。
2. **焊接难度中等偏上**：TQFN-24（0.5mm 间距 + 中心裸焊盘）+ 0402 + 两个通孔 USB 座。建议开钢网 + 热风枪/加热台，EP 裸焊盘必须焊接接地。

> 已修复：底层丝印未镜像（52 处）+ 位号朝向不正（13 处），`silkFlipped` 55→0、ERROR 52→0。
