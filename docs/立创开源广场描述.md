## USB 3.0 ReDriver 中继板（PI3EQX7502）

**一句话**：一块串在链路中间的小板，让整机通过多次转接＋3 米线缆也能跑满 USB 3.0，深度相机正常识别

### 解决什么问题

工作中遇到机器人上 Orin 装在机身内部，深度相机要装在外壳或机械臂末端。用户接口需要通过转接线+接口板的方式对外输出。外接线缆一长，5 Gbps 的 SuperSpeed 信号衰减到链路训练失败，主机自动回落到 USB 2.0 —— 设备能识别但跑不动 USB 3.0

本板串一颗 USB 3.0 ReDriver 在链路中间，做均衡 + 整形 + 去加重后重新驱动，相当于给信号"续一程"。

**实测**：3 m 线直连降级到 480 Mbps ❌ → 串入本板后稳定 5 Gbps ✅

```
主机 ──30cm USB公转公(A公-A公)──► U11 ──► ReDriver ──► USB5 ──3m USB公转Micro-B──► RealSense D450
```

**信号链路**：A 通道跑上行（外设→主机），B 通道跑下行（主机→外设）；USB 2.0 的 D± 直连不进 ReDriver。两个座子都是 Type-A 母座 —— 这块板是**串在链路中间**的，不是终端接口。

### EQ / DE 拨码配置

`EQ_A`/`DE_A`/`EQ_B`/`DE_B` 是三电平脚，用 SW1 拨码切换（上拉 ON = **H**，都 OFF = **M**，下拉 ON = **L**）：

| 配置脚    | 上拉位 | 下拉位 |
| ------ | --- | --- |
| `EQ_A` | 位 8 | 位 7 |
| `DE_A` | 位 4 | 位 3 |
| `EQ_B` | 位 6 | 位 5 |
| `DE_B` | 位 2 | 位 1 |

| 档位          | EQ 均衡量 | DE 去加重量 |
| ----------- | ------ | ------- |
| **L**       | 3 dB   | 0 dB    |
| **M**（芯片默认） | 6 dB   | −3.5 dB |
| **H**       | 9 dB   | −6 dB   |

**EQ 补偿输入之前的线缆，DE 补偿输出之后的线缆** —— 长线在哪一侧，就加大那一侧。

**实测配置（3 m 内直接抄）**：位 1、位 7 ON，其余 OFF → `EQ_A`=L(3dB)、`DE_A`=M(−3.5dB)、`EQ_B`=M(6dB)、`DE_B`=L(0dB)。与作者另一块四路板（内部项目，暂不开源）推出的结果一致。

**想压更远（4~5 m+）**：位 2、位 8 ON，其余 OFF → `EQ_A`=H(9dB)、`DE_B`=H(−6dB)。

> EQ 不是越大越好，开太大会连噪声一起放大。

### 怎么用

1. 用 **USB 公转公（A公-A公）** 线把 **U11** 接到主机的 USB-A 口（实测 30 cm）；
2. 外设用标准 USB 3.0 线接 **USB5**（实测 3 m 的 A公转 Micro-B）；
3. 板子从主机侧 VBUS 取电，无需外接电源。

```bash
lsusb -t    # 5000M ✅ 正常 | 480M ❌ 降级
```

**降级了按这个顺序排查**：

1. **先换 U11 那根 A公-A公线** —— 这线不符合 USB-IF 规范、市售接法不统一，是最常见的坑（实测 30 cm 的可用）
2. 测 U3 pin 1 是否为 3.3V，确认上电
3. 把 `EQ_A`、`DE_B` 往上推一档
4. 缩短外设侧线缆，确认是否超限

### ⚠️ 复刻前请注意

1. **PI3EQX7502AI 已 NRND**（不建议新设计用），官方点名替代型号 **PI3EQX7741AI**。下单前查立创 C526708 库存。
2. **板载 EQ/DE 不是理论最优**（补偿长线的 `EQ_A` 和 `DE_B` 都取最小值），但 3 m 实测够用 —— 靠的是 ReDriver 本身的裸增益。想压更远再调。
3. **2 层板没做 90Ω 差分阻抗控制**。板内走线短（最长 17 mm）实测没问题，追求质量就改 4 层板 + 向板厂提阻抗要求。
4. **焊接难度中等偏上**：TQFN-24（0.5mm 间距 + 中心裸焊盘）+ 0402 + 两个通孔 USB 座。建议开钢网 + 热风枪/加热台，EP 裸焊盘必须焊接接地。
5. 芯片 IO **支持极性反转**（手册写明 pin polarity reversible），差分对正负接反也能工作，布线可放心交叉走线。
6. `EN_A#`/`EN_B#`/`RxD_EN` 悬空是**设计意图**：芯片内部各带 200kΩ 上下拉，悬空正好落在最佳工作状态。

**已知问题**（都不影响实测功能）：电源网络未铺铜、8 处焊盘上走线、5 处盘中孔、38 处 3W 间距不足、10 处丝印压焊盘、原理图 20 条零长度导线、BOM 中 R12 阻值待核对。

> 已修复：底层丝印未镜像（52 处）+ 位号朝向不正（13 处），`silkFlipped` 55→0、ERROR 52→0。
